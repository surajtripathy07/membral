Box 1.3 of `docs/goals/2026-10-25_beyond-claude-mem_goal.md`. A V1-style run of the rung-one stack. **Docker is
still present**: Docker 29.4.0 on a second Colima VM (`membral-w7`), scratch HOME, image built from the tree.

## Not measured, known limits

- No minute timing for this run (image built from the tree; the baseline's cached-image minutes do not compare).
- `local up` waits on the device-name prompt when stdin is not a terminal; close stdin to run it unattended.
- Accepted limits from review: two tabs refreshing back to back inside the reuse window can log the user out (as
  GoTrue does); an old CLI with the new image triggers extraction twice (the queue lease keeps it correct);
  `auth.users.email` is not unique on the stock image (only provisioning creates users).
- npm 11 warns "Unknown project config onnxruntime-node-install"; before npm 12, also set
  `ONNXRUNTIME_NODE_INSTALL=skip` in CI and Vercel env.
