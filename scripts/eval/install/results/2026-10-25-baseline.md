## Friction

- Prerequisites a new user installs first: Node 22.5+, Docker with Compose 2.23+ (Colima needs a VM of 40 GiB disk),
  Ollama, and a 4.7 GB extraction model; the README lists them but `up` does not check for the extraction model.
- `docker compose` was not found under a fresh HOME until `cliPluginsExtraDirs` was added (Homebrew users hit this).
- Extraction needs a 16k Ollama context. An already running Ollama keeps its own, so a second instance on another port
  plus two base-URL lines in `.env` is the documented workaround.
- `local up` on the default port 54621 failed with "Port ... in use" (an ssh forward from Colima); needed another port.
- The default project name collides with older Membral containers/volumes in a reused VM; `--project` avoided it.
- `membral sessions` and the kicker's 2-minute tick sit between import and the first searchable record.
- Fixture sessions older than 30 days are silently "not_queued"; with `--since` default they show as "TOO OLD".
- One record from a 2-minute, 7B-model extraction of a 67-turn session was written already retired, so memory search
  stayed empty. Likely cause, from the code (row not queried before teardown): the D-046 grounding check, which stores a `preference` retired with `unverified:quote_not_found` or `unverified:no_quote` when its quote is not verbatim in a user turn (`apps/cloud/src/lib/memory/grounding.ts:253,303`, `write/insert.ts:71`). Intended behaviour; a 7B extractor paraphrasing the quote is the likely trigger, so the first-run result depends on the extractor.
